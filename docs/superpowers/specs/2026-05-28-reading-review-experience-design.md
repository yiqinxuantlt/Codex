# 读书笔记回顾体验升级设计

## 背景

当前应用是一个单文件 `index.html`，已经具备 CSV 导入、IndexedDB 存储、句子库管理、本地字体导入、主题切换和随机回顾能力。用户希望继续优化界面显示细节、句子库呈现、整体动画、移动端适配，并新增左滑上一条、右滑下一条和阅读记录功能。

本次设计采用“沉浸阅读优先 + 移动端阅读优先”的混合方向：桌面端保持安静、克制、以句子为中心；移动端强化手势、底部操作和触摸可用性。阅读记录采用“简洁摘要 + 每条详情可展开”的方式，并按每条句子的停留时长单独记录。

## 目标

- 优化主阅读界面视觉层级、间距、动画和移动端布局。
- 改善句子库列表显示，让长句、来源、阅读统计和操作更清晰。
- 增加左滑上一条、右滑下一条，同时保留可见按钮作为手势替代。
- 增加每条句子的停留记录，能统计单条累计停留、浏览次数、最近浏览时间。
- 在设置栏中增加阅读记录摘要：今日阅读时长、今日浏览条数、累计阅读时长、最常停留句子。
- 保持单文件 Single Page HTML，不拆成多文件工程。

## 非目标

- 不引入构建工具、框架或服务端。
- 不上传笔记、字体或阅读记录；所有数据仍保存在当前浏览器本地。
- 不做复杂图表库；阅读记录使用轻量卡片、数字和可展开详情呈现。
- 不改变现有 CSV 表头兼容规则。

## 信息架构

设置抽屉保持作为管理中心，入口仍在右下角。

设置首页包含：

- 句子库管理
- 显示、主题与字体
- 阅读记录
- 重新导入 CSV
- 清空句子库

主阅读界面包含：

- 顶部轻量状态：句子总数、今日阅读时长或今日浏览条数。
- 中央引用卡片：更稳定的宽度、行长和移动端字号。
- 底部控制：上一条、随机回顾、下一条。手机端可简化为紧凑底部控制条。
- 手势提示：移动端首次或空闲时以轻量文案提示“左滑上一条，右滑下一条”。

句子库管理包含：

- 新增/编辑表单。
- 句子列表卡片：两行内容预览、来源、浏览次数、累计停留、最近浏览时间。
- 操作：详情、编辑、删除。
- 详情展开后显示完整内容和最近若干次停留记录摘要。

阅读记录包含：

- 摘要卡片：今日时长、今日浏览条数、累计时长、累计浏览条数。
- 热读句子列表：按累计停留时长排序。
- 每条可展开：显示浏览次数、累计停留、最近浏览时间、最近若干次停留片段。

## 数据设计

当前数据库为 IndexedDB，已有 `notes`、`settings`、`fonts` 三个对象仓库。本次升级增加 `readingEvents` 仓库。

`notes` 记录继续使用：

```js
{
  id: "note_xxx",
  content: "...",
  book: "...",
  author: "...",
  chapter: "...",
  remark: "...",
  createdAt: "ISO time",
  updatedAt: "ISO time"
}
```

新增 `readingEvents`：

```js
{
  id: "event_xxx",
  noteId: "note_xxx",
  startedAt: "ISO time",
  endedAt: "ISO time",
  durationMs: 42000,
  source: "random" | "next" | "previous" | "swipe-next" | "swipe-previous" | "initial",
  dateKey: "2026-05-28"
}
```

记录规则：

- 每次显示一条句子时启动停留计时。
- 切换到另一条、页面隐藏、关闭设置前后不会中断计时；只有当前句子离开显示状态或页面进入后台时提交一条事件。
- 停留少于 800ms 的事件忽略，避免误触和初始化噪声。
- 页面进入后台时提交当前事件；回到前台后继续从当前句子开始新的停留。
- 删除句子时不删除历史事件，阅读记录中对已删除句子显示“已删除句子”，避免统计断裂。

统计派生：

- 今日时长：`dateKey` 等于今天的 `durationMs` 总和。
- 今日浏览次数：今天记录过的事件数量，每次切换离开一句话后计为一次。
- 今日浏览句子数：今天按唯一 `noteId` 去重后的句子数量。
- 单条累计：按 `noteId` 聚合 `durationMs` 和次数。
- 最近浏览：每个 `noteId` 最大 `endedAt`。

## 交互设计

### 上一条 / 下一条 / 随机

当前随机逻辑扩展为三种导航：

- `showRandomNote()`：随机抽取非当前句子。
- `showNextNote()`：按当前句子在数组中的下一条，末尾回到第一条。
- `showPreviousNote()`：按当前句子在数组中的上一条，开头回到最后一条。

所有导航都会先提交当前阅读事件，再切换句子，再启动新事件。

### 移动端手势

在引用卡片区域监听 pointer/touch：

- 水平位移超过 48px 且横向移动明显大于纵向移动时触发。
- 左滑触发上一条。
- 右滑触发下一条。
- 垂直滚动不拦截。
- 设置抽屉打开时禁用手势。
- 保留底部按钮作为可访问替代。

### 动画

动画以“阅读器翻页感”为主：

- 句子切换：轻微横向位移 + 淡入，上一条和下一条方向相反。
- 随机切换：轻微上浮 + 淡入，保持当前感觉。
- 设置抽屉：现有滑入保留，调整 easing 和背景遮罩。
- 句子库列表：卡片进入使用短暂淡入，避免大面积跳动。
- 尊重 `prefers-reduced-motion`，禁用位移动画，仅保留必要透明度变化。

## UI 细节

### 主阅读界面

- 使用 `min-height: 100dvh` 改善移动端地址栏高度变化。
- 移动端减少卡片外边距，保持 16px 安全边距。
- 桌面端控制卡片最大行长，避免超宽屏文字过长。
- 顶部状态信息弱化，不抢正文注意力。
- 底部按钮触摸目标不小于 44px。

### 句子库

- 卡片式列表，每条句子稳定高度起步，长文通过两行预览和详情展开处理。
- 显示来源、浏览次数、累计停留、最近浏览。
- 操作按钮顺序为详情、编辑、删除；删除使用弱危险色。
- 空状态说明可以新增或重新导入。

### 阅读记录

- 摘要用四个紧凑数据块。
- 热读句子使用排行式卡片，不使用复杂图表。
- 单条详情展示最近 5 次停留记录。
- 时间格式使用中文友好表达，如 `3分12秒`、`今天 21:14`。

## 可访问性

- 所有 icon-only 或短按钮提供 `aria-label`。
- 手势功能必须有按钮替代。
- 设置视图切换保持按钮焦点可见。
- 阅读记录和句子库的详情使用原生 `details/summary`，保留键盘可用性。
- 颜色继续基于主题变量，黑夜模式保持正文和次要文字对比。

## 测试计划

- 语法检查：提取内联脚本并用 Node `new Function` 检查。
- 浏览器验证：
  - CSV 导入后进入回顾模式。
  - 下一条、上一条、随机均可切换。
  - 移动端 390px 宽度下左滑/右滑触发对应方向。
  - 设置抽屉打开时手势不触发。
  - 阅读事件按单条停留写入 IndexedDB。
  - 页面隐藏或刷新前会保存当前停留记录。
  - 阅读记录摘要和单条详情能正确聚合。
  - 句子库卡片显示浏览次数、累计停留、最近浏览。
  - 黑夜主题下文字和边框仍清晰。
  - `prefers-reduced-motion` 下不出现明显位移动画。

## 风险与约束

- 单文件继续增长，需在脚本内用清晰分区和函数命名控制复杂度。
- 浏览器对 `beforeunload` 的异步 IndexedDB 写入不完全可靠，因此页面隐藏时需要优先保存。
- 阅读事件可能随使用时间增长；先按简单聚合读取实现，后续如果数量很大再考虑按日期索引或清理策略。
- 左右滑动方向容易有理解差异。本设计按用户要求：左滑上一条，右滑下一条。

## 实施顺序

1. 数据库升级：新增 `readingEvents` 仓库和事件读写函数。
2. 阅读会话计时：在句子切换、页面隐藏和初始化时提交停留记录。
3. 导航扩展：新增上一条、下一条和带方向的切换动画。
4. 手势支持：在卡片区域加入左滑/右滑识别。
5. UI 优化：主界面、句子库和设置抽屉的移动端布局与细节打磨。
6. 阅读记录视图：摘要、热读句子、详情展开。
7. 验证：桌面、移动端、黑夜主题、减少动画模式和 IndexedDB 数据检查。
